# 📋 Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-09-01
### Added
- Comprehensive GitHub Actions CI/CD pipelines.
- Multi-container Docker Compose and multi-stage Dockerfiles.
- Emergency SOS distress beacon and international helpline directory.
- Graph-reduction debt simplification algorithm for group expenses.
- Destination weather forecasting and climate advisory service.
- AI travel itinerary generator and carbon footprint calculator.
- Interactive travel toolkit: Packing List, Currency Converter, SOS Modal, Splitwise Graph.
- Progressive Web App (PWA) manifest and offline service worker.
- Unit test suites covering backend services and utilities.

## [1.0.0] - 2026-03-24
### Added
- Complete user profile with personality matchmaking.
- Real-time location tracking and Leaflet map integration.
- Group trip creation, invite codes, and member roles.
- Real-time WebSockets group chat.
